# Text-Count

![Learning Project](https://img.shields.io/badge/Status-Projeto%20de%20Aprendizado-blue)

Ferramenta CLI em Python para contar linhas e palavras de arquivos de texto.

Projeto educacional desenvolvido para praticar Python e manipulação de arquivos ✅

## Como rodar

```bash
git clone https://github.com/Arthurcodehub/text-count.git
cd text-count
python main.py
```
# no Linux, use python3

Digite o caminho do arquivo (com ou sem aspas) e receba a contagem de linhas e palavras.

## Recursos

- Contagem de linhas
- Contagem de palavras
- Aceita caminho com ou sem aspas
- Mensagem clara em caso de erro ao abrir o arquivo
